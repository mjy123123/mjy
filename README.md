# 我的工具箱 · 三个私人 PWA

三个只给自己用的小应用，**一次部署，可以在 iPhone 主屏上放三个独立图标**。
无账号、无服务器、无数据库、不联网也能用，数据全部只存在你自己手机里。

| 工具 | 干什么 | 部署后访问 |
|---|---|---|
| 📖 答案之书 | 心里想一个问题，翻开它给一句提醒 | `/answer/` |
| 🔮 每日运势 | 真实历法（干支/节气/月相/星盘）+ 星座专属文案 | `/fortune/` |
| 💼 简历岗位匹配 | 看你的简历适合投什么岗位，还能对比 JD | `/jobs/` |
| 🎓 每日一课 | AI 产品经理 180 课，带存档、收藏与笔记 | `/learn/` |

根路径 `/` 是一个工具箱首页，把四个入口列在一起。

## 二、本机先看一眼

`localhost` 算安全上下文，所以在电脑上就能验证 Service Worker 和离线。

```powershell
python -m http.server 8080
```

打开 <http://localhost:8080>，F12 → Application：

- **Manifest** 应能读到「我的工具箱」
- **Service Workers** 应显示 `activated and is running`
- 勾 Network 的 **Offline** 再刷新，页面应该照常打开

> ⚠️ 手机直接访问 `http://192.168.x.x:8080` **装不了 PWA**：Service Worker 和「添加到主屏幕」都要求 HTTPS，只有 `localhost` 例外。所以必须部署。

## 三、部署到 HTTPS（三选一，都免费）

详细步骤见 [DEPLOY.md](DEPLOY.md)。

### 方案 A：Cloudflare Pages ⭐ 推荐

仪表盘 → Workers & Pages → Create → Pages → **Upload assets** → 上传 `my-apps-deploy.zip`。

**为什么推荐它**：对静态资源**不限流量、不限请求**，怎么改都不会撞额度。

### 方案 B：Netlify

1. 打开 <https://app.netlify.com/drop>
2. 把整个 **`my-apps` 文件夹**（或 zip）拖进去
3. 得到 `https://随机名.netlify.app`

> ⚠️ Netlify 免费版是**积分制**：每月 300 积分，而**每次生产部署扣 15 积分**——一个月只能部署约 20 次。用完就拒绝新部署（已有站点仍在线）。频繁小改很容易撞墙，所以别把它当主力。

### 方案 C：GitHub Pages

免费、自带版本历史，但需要一个**公开**仓库。**详细步骤（含完全不装 git 的网页上传路线）见 [GITHUB-PAGES.md](GITHUB-PAGES.md)。**

一句话版：网页把 `my-apps` **里面的东西**全选上传到仓库根目录 → 手动建一个空的 `.nojekyll` → Settings → Pages → `main` / `/ (root)`。
代码里全部用相对路径，所以部署在 `/仓库名/` 子目录下也不会 404。

## 四、装到 iPhone（可以放 5 个图标）

**必须用 Safari**（Chrome、微信内置浏览器都不行）：

1. Safari 打开你的 `https://…` 地址
2. 点底部 **分享** 按钮 → 往下滑 → **「添加到主屏幕」**
3. 想再要一个工具图标：**先访问那个工具页面**，再重复 1-2 步

于是你可以得到：

| 访问的地址 | 主屏图标名字 |
|---|---|
| `https://xxx.netlify.app/` | 工具箱 |
| `https://xxx.netlify.app/answer/` | 答案之书 |
| `https://xxx.netlify.app/fortune/` | 每日运势 |
| `https://xxx.netlify.app/jobs/` | 岗位匹配 |

每个都是全屏独立窗口，没有地址栏，和其他 App 一样。

## 五、改了代码怎么更新

1. 重新部署
2. **把 `sw.js` 里的 `const CACHE = 'myapps-v4'` 改成 `'myapps-v5'`**（以后每改一次 +1）—— 不改的话手机可能一直吃旧缓存
3. 手机上把 App 打开**两次**（第一次在后台换缓存，第二次生效）

还不行就删掉主屏图标重新添加，或在 设置 → Safari → 高级 → 网站数据 里删掉该站点。

## 六、四个工具分别怎么用

### 📖 答案之书
心里默想一个问题（也可以在输入框里写下来，**只显示、不保存**），点「翻开」。
可以反复「再问一次」，也可以点「开启摇一摇」后晃手机抽签。

240 条答案，分 10 个类别（行动 / 等待 / 沟通 / 直觉 / 放下 / 坚持 / 改变 / 边界 / 当下 / 信任），每条带类别标签。
文案是**自我对话用**的，不预测吉凶、不涉及医疗投资建议。

### 🔮 每日运势

第一次进去填**昵称 + 出生日期 + 出生时间 + 出生地**（时间是选填，但填了才算得出上升星座）。
顶部可切「昨天 / 今天 / 明天」。

页面分成两层，界面上也分开标注了：

**① 真实推算层**（数据由本地算法实时算，不是随机数）

| 项目 | 依据 | 与官方数据对账 |
|---|---|---|
| 干支纪年/月/日 | 六十甲子 + 五虎遁，立春换年、节气换月 | 3 个日期全中 |
| 二十四节气 | 太阳视黄经求根（Meeus） | vs 日本国立天文台 **最大 8 分钟** |
| 月相与朔望 | 月亮黄经 60 项级数 − 太阳黄经 | vs NAOJ **最大 2 分钟** |
| 二十八宿值日 | `(JDN + 11) mod 28`，含七曜与动物名 | 毕月乌/觜火猴/氐土貉 全中 |
| 冲煞 | 地支六冲 + 三合局 | 冲马煞南等 全中 |
| 彭祖百忌 | 十干十二支固定表 | 全中 |
| 太阳/月亮/上升星座 | 恒星时、黄赤交角、黄经分区 | 用独立球面天文学公式反算地平高度 ≈ 0° |

**② 娱乐内容层**：总评星级、事业/财运/感情/健康评分、宜忌、幸运色/数字/方位/时段、今日建议。
由 `日期|昵称|生日|时间|地点` 做种子的确定性伪随机生成（xmur3 + mulberry32），
**同一天同一个人结果永远一模一样**——不然每天刷新就变，这个 App 就没意义了。

**文案取自本人星座的专属内容池**：12 星座各 14 条「宜」+ 14 条「忌」+ 每档 8 条总评 + 每档 7 条建议，
按四象（火/土/风/水）、守护星、性格特质写，**12 个星座的池子两两之间零重复**。
宜忌里会混一条生肖专属的（带虚线边框区分）。

> ⚠️ **刻意没有做的两项**，页面里也写了原因：
> - **黄历宜忌**——查了两个黄历来源，同一天的结果**互相矛盾**，它不是可计算的真值，是各家择日流派的取舍。
> - **建除十二神**——按《协纪辨方书》「月建上起建」的规则，和主流商业黄历差一天（口径不同）。
>
> 与其给一个和黄历对不上的数字，不如不给。
>
> 而且说清楚：**星座运势没有可计算的真值**，真人写的运势也是编的。这里能做到的是让它**有依据、有体系**，但**不会因此变准**——它仍然是娱乐。

### 💼 简历岗位匹配
把简历整段粘进来 → 得到：

- **简历画像**：自动抽出工作年限（支持「3 年经验」和「2020.03 - 2023.06」两种写法，多段经历会累加）、学历、识别到的技能关键词
- **推荐投递方向**：28 个岗位族按匹配强度排序，列出命中的核心词/加分项，每个岗位还给一条投递建议
- **JD 对比**：把想投的岗位描述粘进来，告诉你哪些要求你已有、哪些是缺口
- **搜索关键词**：点一下复制，直接粘到 BOSS 直聘 / 猎聘的搜索框

隐私：简历只存在手机本地，不上传。因为这个工具是纯前端的，**没有任何网络请求**。

> ⚠️ 说清楚：这是**本地关键词词典的匹配**，不是 AI 语义理解。它能帮你快速定位投递方向、发现 JD 里的能力缺口，但不会替你做判断。

### 🎓 每日一课
AI 产品经理的 180 课，5 个模块各 36 课：

| 模块 | 覆盖 |
|---|---|
| AI 技术基础 | Token、上下文窗口、幻觉成因、RLHF/DPO、Embedding、RAG、LoRA、MoE、推理模型… |
| AI 产品方法论 | 什么场景**不该**用大模型、容错设计、三种交互范式、评测集冷启动、成本与路由… |
| 落地实践 | RAG 全链路、Agent 四种设计模式、幻觉三层治理、提示词注入、事故复盘… |
| 商业与行业 | 模型选型、三种定价、毛利结构、法律/医疗/教育/金融/电商案例… |
| 协作与沟通 | 怎么跟算法同学说话、面试答题框架、风险清单怎么写… |

每条课的结构：**一句话定义 → 为什么产品经理要知道 → 3–4 条核心要点 → 一个带数字的真实例子 → 一个常见的坑 → 今日一题（3 选 1 + 解析）**。落点统一在「这对做产品意味着什么」，不是技术百科。

每日推送按**模块轮转**排序（技术 → 方法论 → 实践 → 商业 → 软技能 → 技术…），所以不会连着 36 天只讲一个方向。页面四个页签：**今日 / 存档 / 全部 / 我的**。

进度从**你第一次打开那天**起算，第 1 天 = 第 1 课。漏了哪天在「存档」里点回去补就行，「全部」可以按模块跳着复习。进度、收藏、笔记都存在 localStorage，「我的」页可一键导出 JSON。

**每天提醒**：App 本身是纯本地的，做不到定时推送（iOS 的 PWA 没有这个能力）。用 iOS 快捷指令补上，见 [每日提醒.md](每日提醒.md)。

`learn/days.json` 是一份只含 180 个课程标题的极简文件，专门给 iOS 快捷指令抓取用。

## 七、自测（可选）

仓库里带了三套回归测试，改完代码可以自己跑一遍：

```powershell
node tools/test_almanac.js    # 39 项：干支/节气/月相/二十八宿/冲煞 对账 + 上升星座自洽
node tools/test_fortune.js    # 44 项：确定性、星座专属、星盘、分数区间
node tools/test_learn.js      # 38 项：课程库结构、模块轮转、黑话扫描、日期换算
node tools/test_jobs.js       # 44 项：关键词边界、年限解析、岗位排序、JD 对比
```

`test_almanac.js` 里有两类测试值得说明：

- **对账测试**：把算出来的干支、二十八宿、冲煞、彭祖百忌，逐个和真实黄历的 2024-01-01 / 01-02 / 02-10 三个日期比对。
- **自洽测试**：上升星座不是拿现成答案对的（找不到可信的对照表），而是**用独立的球面天文学公式反算**——把算出的上升点黄经换算成赤道坐标再算地平高度，正确的话必须是 0°，而且随时间推移要在上升而不是西沉。240 组样本零偏差。

`test_jobs.js` 带了**防误命中**的用例：`java` 不命中 `javascript`、`ai` 不命中 `email`、`hr` 不命中 `through`、`gin` 不命中 `login`、`hive` 不命中 `archive`，同时保证 `MySQL8.0`、`Vue3`、`HTML5`、`C++` 依然能命中。

`test_learn.js` 除了查结构，还会扫**空话黑话**（赋能/抓手/闭环/颗粒度/组合拳/颠覆…），并用「前三个字的去重数」检测内容是不是靠模板套出来的。

### 改课程内容

课程内容不在 `course-data.js` 里手改，而是改源文件再重新装配：

```powershell
# 1. 改 tools/course-parts/ 下的 5 个 json（tech / method / practice / biz / soft）
# 2. 校验并装配
node tools/build_course.js
# 3. 跑测试
node tools/test_learn.js
```

装配脚本会做这些事：校验条数、id 连续性、字段字数、题目合法性、标题查重，然后**按模块轮转交错排序**成每日课程序列（不然会是 36 天纯技术、36 天纯方法论），最后写出 `learn/course-data.js` 和 `learn/days.json`。校验不通过会直接失败并列出所有问题。

### 换图标

图标是脚本生成的矢量图，一套五个符号：**bento 三格**（工具箱）、**摊开的书**（答案之书）、**月牙+星**（每日运势）、**文档**（岗位匹配）、**学士帽**（每日一课）。

```powershell
python tools/make_icons.py --preview     # 生成三方向对比图，不动正式图标
python tools/make_icons.py --style a     # 应用（a 深色渐变 / b 纯色扁平 / c 浅底彩符号）
```

- **a** 深色渐变 + 白色符号，带顶光和投影 —— 当前用的
- **b** 纯色扁平 + 白色符号
- **c** 浅底 + 彩色符号，像 iOS 备忘录

想换配色：改脚本里的 `PALETTE`。想换符号形状：改 `sym_grid` / `sym_book` / `sym_moon` / `sym_doc` / `sym_cap`。

⚠️ 换完图标后，iOS 主屏上的旧图标**不会自动更新**，必须**删掉图标重新「添加到主屏幕」**。

## 八、数据安全

四个工具的数据都在各自浏览器存储里，**互相独立，且只有这台手机有**：

| 风险 | 说明 |
|---|---|
| 清理 Safari 数据 | 在系统设置里清一次，运势资料和简历就没了 |
| 换手机 / 刷机 | 不会自动同步 |
| iOS 自动清理 | 没加到主屏的站点长期不用会被清存储；加到主屏后不受这条限制，但系统空间极度紧张时仍可能被回收 |

运势的昵称生日、简历文本都是**你随时能重新填一遍**的东西，丢了成本很低。
真正要小心的是如果你以后往这些工具里加「长期积累的记录」——那时候一定要加导出功能。

## 九、常见问题

**Q：主屏图标名字不对 / 还是旧图标？**
iOS 是在「添加到主屏幕」那一刻读取名字和图标的。改完要**删掉图标重新添加**。

**Q：四个工具能各自独立更新吗？**
不能，它们共享一个 `sw.js` 和一次部署，改任何一个都要重新部署整站。

**Q：想让岗位推荐更准（真 AI 语义匹配）？**
现在完全离线所以只能做关键词匹配。要更准就得接大模型 API，那意味着：要么把你的 API Key 存在手机本地（有泄露风险），要么加一个后端（不再是纯静态、要花点钱）。想走这条路可以再聊。

**Q：加个密码锁？**
纯前端密码锁只能防「别人拿到你解锁的手机随手翻」，防不了懂技术的人。真要加密得用 WebCrypto + 你的口令派生密钥把内容加密后再存。
